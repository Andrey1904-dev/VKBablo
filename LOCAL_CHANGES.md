# Изменения в переданном архиве

Исходник: загруженный пользователем `VKBablo-main.zip` (main). Он **не включает** последние изменения ветки `arena/23498f80-vkbablo`. Не объединяйте изменения механически: сначала сравните с актуальной веткой.

- Переведены на `getBackend()` страницы: Analytics, Notifications, Characters, Communities, Dashboard, Settings.
- Для GitHub Pages включены HashRouter и условный Vite base `/VKBablo/`.
- Добавлен GitHub Actions workflow для публикации **только демо-сборки**.
- Добавлена инструкция `CODEX_SETUP.md` для последующего подключения Supabase/VK/AI через Codex.
- В Settings исправлено устаревшее упоминание Cloudflare; сохранение AI-ключа перенаправлено в серверный контракт `saveAiKey`.

## Ограничения

- Остальные страницы ещё требуют миграции на `getBackend()`.
- Supabase не подключался; VK API и платные AI API не вызывались.
- Облачные интеграционные тесты и проверка в браузере не выполнялись.
- В данной среде `npm ci` не завершился (таймаут), поэтому **typecheck, test, build после изменений не подтверждены**. Перед merge обязательно запустите их.
